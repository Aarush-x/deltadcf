# Gstack Skills Available
You are equipped with the gstack role-based framework. Read the instructions for the following skills from `~/.gstack-tools/` when the user invokes these slash commands:
- /office-hours: Act as a product manager to scope the idea.
- /plan-ceo-review: Act as a CEO to cut bloat and review strategy.
- /plan-eng-review: Act as an Engineering Manager to review architecture.
- /design-review: Act as a UI/UX designer.
- /qa: Act as a QA tester using browser automation.
- /ship: Act as a release manager.
